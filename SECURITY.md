# Security Policy

## Supported versions

The current `main` branch is supported. Older snapshots may not receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository when available:

<https://github.com/khuang9104/Project-Tome/security>

Include only the information needed to reproduce and assess the issue. Do not publish credentials, private source code, personal data, or an exploit before the issue has been reviewed.

If private reporting is not available, open a public issue containing only a request for a private contact channel; do not include vulnerability details.

## Disclosure

We will acknowledge reports when practical, investigate the affected scope, and coordinate disclosure after a fix or mitigation is available.
