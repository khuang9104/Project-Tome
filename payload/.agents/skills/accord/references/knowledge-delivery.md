# Optional knowledge delivery

Preview selection with accord-project.mjs --publish. Use accord-knowledge-export.mjs
--help for explicit source-free delivery and integrity verification. Inspect audience,
module selection and permissions. Export excludes source/control files and rejects
obvious credential material; it cannot prove prose free of confidential facts.

Refs can require omitted context: disclose it. Checksums establish a file set, not
semantic completeness, production state or authorization to publish externally.
