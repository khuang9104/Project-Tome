# Durable project memory

Read current intent before interpreting a new request. Separate the user's problem
and desired outcome from proposed solutions. Preserve useful requirement IDs,
vocabulary, constraints, non-goals and acceptance examples in their existing owner.

When a decision changes, record the new meaning, reason and superseded premise.
An inferred preference stays an Assumption/Proposal. Contradictions between code,
design and needs remain an Open question until reconciled; do not rewrite intent
to fit code. A clear correction is enough to update its scoped decision without
another approval ceremony.

The continuity entry records active outcome, relevant links, unfinished work,
material unknowns and next steps. It routes a fresh Agent into canonical detail,
not chat history or a second specification. Update at useful work boundaries and
when goals change. Significant conclusions should survive a lost conversation.
